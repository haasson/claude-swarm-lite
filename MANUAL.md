# Swarm — инструкция для пользователя

Пульт для нескольких сессий Claude Code сразу. Каждая вкладка — настоящий процесс
`claude`, запущенный в твоём login-шелле. Приложение **не трогает токены и авторизацию**:
работает на твоей обычной подписке, ровно как `claude` в терминале. Вместо прыганья по
вкладкам терминала ты видишь дашборд — кто работает, кто ждёт ответа, кто закончил.

macOS, Apple Silicon (arm64).

---

## Что нужно до старта

1. **Claude Code установлен и залогинен.** Проверь в терминале:
   ```bash
   claude --version
   ```
   Если команды нет — сначала поставь и авторизуй Claude Code. Swarm просто запускает
   этот же `claude`, так что без него работать не будет.

2. **macOS на Apple Silicon** (M1/M2/M3/…). Сборка — arm64.

---

## Установка (для обычных пользователей)

1. Возьми файл **`swarm-<версия>-arm64.dmg`** (папка `dist/` в проекте).
2. Открой `.dmg`, перетащи **Swarm** в **Applications**.
3. Первый запуск macOS заблокирует: подпись у сборки ad-hoc. Сними карантин командой
   в терминале — это делается один раз:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Swarm.app
   ```
   Без терминала: попробуй открыть Swarm, получи отказ, потом в **Системные настройки →
   Приватность и безопасность** нажми **Open Anyway** — раньше неудачной попытки этой
   кнопки там нет. Правый клик → Open, который работал на старых macOS, в 15 и новее
   отключён.

> При первом запуске в новой папке macOS может спросить доступ к файлам — разрешай,
> это нужно `claude`, чтобы читать проект.

## Запуск из исходников (для разработчиков)

```bash
npm install     # ставит зависимости и пересобирает node-pty под ABI Electron
npm start       # запускает приложение
```

Собрать свой `.dmg`:
```bash
npm run dist    # результат в dist/
```

## Как пользоваться

### Создать агента
- **⌘T** — новая вкладка в папке по умолчанию (`~/ClaudeSwarm`).
- **⌘O** — новая вкладка с выбором рабочей папки (folder picker). Запускай агента прямо
  в папке нужного проекта — так `claude` видит твой код.

Каждая новая вкладка сама запускает `claude` и подхватывает твою авторизацию.

### Переключение и закрытие
- **⌘1 … ⌘9** — прыгнуть на вкладку по номеру.
- **⌘W** — закрыть текущего агента (процесс `claude` завершается).

### Раскладка
- **⌘L** — переключить вид: рейл слева ⇄ плашки-дашборд сверху. Выбор запоминается.

### Панель команд
- **⌘K** (или кнопка-бургер) — меню команд: встроенные + автоматически найденные
  кастомные слэш-команды и скиллы **этого проекта** (`.claude/commands`, `.claude/skills`)
  и глобальные (`~/.claude/…`). Команды с «…» ждут, что ты допишешь аргумент.

### Организация карточек
- **Двойной клик** по названию карточки — переименовать (можно в несколько строк).
- **Drag & drop** — перетаскивай карточки и группируй их по папкам.

## Статусы агентов

Цвет карточки показывает, что происходит, без чтения терминала:

| Статус | Что значит |
|--------|-----------|
| 🟠 **работает** | Claude активно печатает / думает / гоняет инструмент |
| 🟡 **ждёт ответа** | остановился на вопросе или запросе разрешения — нужен ты |
| 🟢 **готов** | закончил, ждёт нового задания |
| ⚪ **завершён** | сессия закрыта / процесс вышел |

Статус берётся из трёх источников, в порядке старшинства:

1. **Хуки Клода** (включаются в «Настройки → Запуск») — единственный канал, который
   видит диалоги: «просит разрешение», «задал структурный вопрос».
2. **Стенограмма** — Клод пишет каждое сообщение в свой журнал по ходу дела, и
   приложение его читает. Отсюда «работает / думает / конец хода» без угадывания, и
   отсюда же берётся текст вопроса — дословно и целиком, даже если на экране он уже
   уехал вверх. Вкладка привязана к своему журналу точно, файлы не путаются.
3. **Экран** — подстраховка: диалог разрешения виден только там, и там же работает
   старая логика для вкладок, где Клод запущен не приложением.

Один случай не виден ни одному каналу сам по себе: Клод заканчивает ход одинаково и
когда работа сделана, и когда он задал вопрос текстом. Отличает их только то, как
агент заканчивает сообщение — по умолчанию «Сейчас от тебя: …». Свой список фраз
задаётся в «Настройки → Запуск» (по одной в строке); «Сейчас от тебя: ничего,
жди…» вопросом не считается.

Просить об этом агента самому не нужно: галочка **«Просить агента звать вас»** (там же,
включена по умолчанию) добавляет просьбу прямо в запуск — спрашивать через выбор
вариантов, а вопрос в тексте заканчивать вашей фразой. Ваши файлы при этом не меняются:
просьба живёт только во вкладках, запущенных приложением. Если тот же агент нужен вам и
в обычном терминале, кнопка **«Скопировать правило для CLAUDE.md»** даёт то же правило
готовым блоком — вставьте его в `CLAUDE.md` проекта или в свой `~/.claude/CLAUDE.md`,
и оно будет работать везде.

### Фоновые уведомления
Когда агент в фоне переходит в **«ждёт ответа»** или **«готов»**, прилетает системное
уведомление macOS. Клик по нему выводит приложение на передний план к нужной вкладке —
можно запускать несколько агентов и не сидеть, уставившись в экран.

## Телеграм: отвечать агентам с телефона

Встал из-за компьютера — агенты продолжают писать. «Настройки → Телеграм» связывает их
с вашим телефоном.

**Настройка, один раз.** Панель «Настройки → Телеграм» — мастер из трёх шагов, и у
каждого шага справа стоит галочка, когда он сделан. Идти можно сверху вниз, не
запоминая ничего наперёд.

1. **Заводим бота.** В Телеграме напишите `@BotFather` → `/newbot` → получите токен вида
   `1234567890:AA…` и вставьте его в первый шаг. Бот — это аккаунт в Телеграме, а не
   программа на сервере: размещать и платить нечего.
2. **Привязываем группу.** Создайте группу (можно одному), включите в её настройках
   **«Темы»**. Нажмите «Привязать группу» → отсканируйте QR телефоном (или нажмите ссылку
   рядом, если Телеграм стоит на этом маке) → отправьте показанный код в эту группу.
   Код действует 15 минут. Осталось сделать бота **администратором**.
3. **Мост в эфире.** Третий шаг показывает, что всё сошлось: имя группы, состояние связи
   и короткая памятка, как этим пользоваться.

Под вторым шагом висит живой список требований — группа, темы, бот в группе, админство,
право «Управление темами», право «Удаление сообщений». Каждый пункт с галочкой или
крестиком, так что видно всё сразу, а не по одной беде за нажатие: поправили в Телеграме —
нажали «Проверить ещё раз» — список перерисовался.

Нужна именно **группа с темами**: у сворма много вкладок одновременно, и различать их на
телефоне можно только темами. Личный чат с ботом приложение привязывать откажется: без тем
не отделить агентов друг от друга, а без админства Телеграм (режим приватности ботов)
вообще не покажет боту обычные сообщения в темах — только реплаи на его собственные.

**Как этим пользоваться.** Список тем группы — это список вкладок:

```
Мои агенты
├── api        2   ❓ миграцию катать сразу или ждать?
├── web            ✅ собрал, тесты зелёные
└── landing        ✅ готов
```

Заходите в тему нужной вкладки и просто пишете — текст уходит в живую сессию, как будто вы
набрали его на клавиатуре. Ни реплаев, ни команд для этого не нужно: тема и есть адрес.
Реплай тоже работает, если удобнее ответить на конкретное сообщение. Общая тема группы —
служебная: там работают команды, а обычный текст останется без адресата, о чём бот и напишет.

**Имена и темы держатся вместе — в обе стороны.** Переименовали вкладку на маке — тема в
группе переименуется следом. Переименовали тему пальцем в телеге (в дороге это
единственный способ навести порядок) — переименуется вкладка на маке, и `/tabs` назовёт её
уже новым именем. Тема заводится вместе со вкладкой и исчезает вместе с ней. А если тему
закрыть руками, а вкладка ещё работает, бот спросит прямо в ней: **↩️ вернуть тему** или
**✖️ закрыть вкладку**. Молча завершать агента по жесту в чате он не станет — вместе с ним
пропал бы незаконченный ход.

| Команда | Что делает |
|---|---|
| `/tabs` | вкладки и что у них сейчас (работает / ждёт / готов) |
| `/last` | что агент сказал последним (в теме вкладки), даже если он ещё работает |
| `/phone` | я с телефоном: писать сюда обо всём, маку не спать |
| `/comp` | я вернулся за компьютер: молчать, пока не спрошу |
| `/usage` | расход: заполнение контекста, окно 5 часов и неделя, со временем сброса |
| `/sync` | подтянуть темы под открытые вкладки и закрыть темы от закрытых |
| `/new` | ещё один агент в папке этой темы (в теме вкладки) |
| `/help` | короткая напоминалка |

`/usage` в теме вкладки покажет её контекст, в общей теме — контекст всех вкладок, самые
полные сверху: это ответ на вопрос «кого пора сжимать». Окна подписки (5 часов и неделя) —
общие на аккаунт, поэтому называются один раз. Числа приходят от самого Клода, поэтому у
вкладок, где строка статуса не наша, вместо процента будет прочерк с причиной.

Обычно `/sync` не нужен — темы держатся в такт сами. Он для случаев, когда такт сбился:
приложение закрыли жёстко, группу привязали раньше, тему удалили руками.

Когда агент закончит ход, его ответ придёт в ту же тему. По задачам из телеги — всегда;
по остальным — смотря **где вы сейчас**. За столом мост молчит: вы сидите перед этими
вкладками и всё видите сами. Хотите, чтобы он писал всегда, — галочка «писать всегда, даже
когда я за компом» в настройках.

**«Где я» — иконка в правом нижнем углу.** Клик открывает выбор из двух положений:

| Положение | Что мост пишет сам | Сон мака |
| --- | --- | --- |
| **за компом** | ничего | как обычно |
| **за телефоном** | вопросы, разрешения, итоги всех ходов | мак не засыпает |

Молчание касается только того, что мост затевает сам. На спрошенное он отвечает всегда:
команды работают, и ответ на отправленное вами сообщение придёт, где бы вы ни были.
Насколько подробно отвечать — отдельная настройка («кратко» / «полностью»), от того, где
вы, она не зависит.

Загрузили десяток агентов и собрались уходить — выберите «за телефоном». Иконка загорается
жёлтым и так и горит: приложение не угадывает, когда вы вернулись, — вернувшись, выберите
«за компом». Это осознанно. Момент, когда человек ушёл, знает только человек: по простою
мыши выходило и «зеркало включилось само, пока я читал», и — хуже — «первые итоги
пропали», потому что они приходят в первые минуты после того, как вы встали.

**Ушли и забыли переключить — скажите боту `/phone`.** Приложение осталось на столе, а
телефон с вами: команда делает ровно то же самое и сразу досылает итоги ходов, которые
закончились, пока зеркало было выключено (уже отправленное не повторяется). `/comp` —
вернулись за стол. А `/last` в теме вкладки покажет, что её агент сказал последним, даже
если он ещё работает.

Выбранное живёт до перезапуска приложения: запустилось — значит вы за компьютером. Кому
зеркало нужно всегда, тому нужна галочка в настройках, а не эта иконка: с ней иконка
пропадает совсем — выбирать нечего, итоги идут всегда, — а «я ушёл» говорится с телефона.

Иконка появляется только с привязанной группой: без неё зеркалить некуда.

**Агент знает, что вы в телеге.** К сообщениям из телеги приложение добавляет метку и
просьбу отвечать по-телефонному — без стен кода и без интерактивного выбора вариантов,
такой выбор с телефона просто нечем нажать. При включённых хуках это не просьба, а запрет:
инструмент с вариантами блокируется, и агент переспрашивает текстом.

Насколько подробно отвечать, решаете вы: в настройках моста есть **«Кратко»** (по
умолчанию — суть в паре фраз) и **«Полностью»** (как за компьютером; длинный ответ придёт
несколькими сообщениями). Это именно просьба к агенту, а не обрезка готового ответа —
оборванная на полуслове мысль была бы хуже коротко изложенной. Кому мало двух заготовок,
рядом прячется «Своя формулировка».

Как только вы тронете клавиатуру в этой вкладке, режим снимается — вы вернулись за стол,
значит и большие ответы, и варианты снова уместны.

**Мак не должен спать.** Агенты живут на нём, поэтому со спящим маком отвечать некому.
В настройках есть галочка «не давать компьютеру засыпать, пока вас нет» (включена) — она
работает в положении «за телефоном»: пока вы рядом, сон вам не мешает, а батарею беречь
незачем только тогда, когда вы в дороге и ждёте ответов. Если мак всё-таки уснул — Телеграм придержит
ваши сообщения и отдаст их, когда приложение проснётся.

**Чего мост намеренно не делает.**
- Не угадывает вкладку. Написали в общую тему без реплая — придёт «здесь я не знаю, к кому
  обращаться», а не попытка догадаться: ответ, уехавший в чужую задачу, хуже отсутствия ответа.
- Не принимает разрешение **словами**. Запрос приходит с кнопками, на которых стоят
  варианты самого Клода, и в сообщении видно, что одобряется (включая команду). Написать
  «да» текстом нельзя: одобрить можно только то, что было в списке. Если между отправкой
  и нажатием запрос успели закрыть за компьютером, кнопка ответит «запрос уже закрыт» и
  ничего в сессию не напечатает.
- Не слушает чужих. Привязан ровно один чат; сообщения из любого другого игнорируются.

**Что нужно знать про доступ.** Приложение само звонит на `api.telegram.org` (long
polling): наружу не открывается ни порт, ни адрес, VPS не нужен. Обратная сторона —
если Телеграм у вас работает только через VPN, то и мост тоже. Токен хранится
зашифрованным ключом системного keychain; в интерфейсе он больше не показывается,
только маска — если потеряли, выпустите новый у BotFather.

**Голосом.** Запишите голосовое в тему вкладки — сворм распознает его **на вашем маке**
(whisper.cpp, звук никуда не уходит) и пришлёт эхо: «🎙 → api: посмотри, почему падает
тест». Эхо не для красоты: распознавание ошибается на названиях продуктов, и увидеть это
надо до того, как агент начнёт по нему работать.

Один раз настроить: в «Настройки → Телеграм» указать модель (файл `ggml-*.bin`), а путь к
бинарнику можно оставить пустым, если он в PATH. Там же написано, что поставить — на маке
`brew install whisper-cpp`, на Windows готовый бинарник из релизов whisper.cpp.

## Типичный сценарий

1. **⌘O** → выбираешь папку проекта → агент стартует в ней.
2. Даёшь задачу, он уходит в **работу** (🟠).
3. Переключаешься **⌘T / ⌘O** на второго агента в другом проекте.
4. Первый упёрся в вопрос → уведомление + карточка стала 🟡 → возвращаешься, отвечаешь.
5. Позеленел (🟢) — даёшь следующую задачу или **⌘W** закрываешь.

## Если что-то не так

- **«claude: command not found» во вкладке** — Claude Code не в PATH login-шелла.
  Проверь, что `claude --version` работает в обычном терминале; поправь `~/.zshrc`.
- **Не запускается после установки** — сними карантин: `xattr -dr com.apple.quarantine
  /Applications/Swarm.app` (см. «Установка»).
- **Ложный «готов» на долгой паузе** — приложение специально давит такие ложняки, но при
  очень тихих операциях статус может дёрнуться; ориентируйся по самому терминалу вкладки.
- **Сыплются запросы доступа к файлам** — запускай агентов в конкретных рабочих папках
  (**⌘O**), а не в домашней директории.

## Горячие клавиши — шпаргалка

| Клавиши | Действие |
|---------|----------|
| ⌘T | новый агент (папка по умолчанию) |
| ⌘O | новый агент с выбором папки |
| ⌘W | закрыть текущего агента |
| ⌘1–9 | переключиться на вкладку |
| ⌘L | сменить раскладку |
| ⌘K | панель команд |
