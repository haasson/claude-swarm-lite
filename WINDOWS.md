# Claude Swarm Lite — запуск на Windows

Короткая версия: поставь Node.js, распакуй эту папку, дважды кликни
**`установка-и-запуск.bat`**. Компилятор/Python не нужны — терминал ставится
готовым бинарником.

---

## Что нужно один раз поставить

1. **Node.js LTS** — https://nodejs.org (кнопка «LTS»).
   Галку «Automatically install the necessary tools…» ставить **не обязательно** —
   мы используем готовые бинарники, компилировать ничего не надо.

2. **Claude Code** — приложение просто запускает команду `claude` в терминале.
   Проверь, что в обычном PowerShell команда `claude` работает. Если нет —
   сначала установи/настрой Claude Code, иначе вкладки будут пустыми.

---

## Как запустить

Дважды кликни **`установка-и-запуск.bat`**.

Первый запуск скачивает зависимости (Electron ~90 МБ + готовый бинарник
терминала) — пару минут. Дальше приложение стартует. При следующих запусках
можно кликать тот же файл — он увидит, что всё уже стоит, и просто запустит.

---

## Как собрать `.exe` (установщик)

Дважды кликни **`собрать-exe.bat`**. Готовый файл появится в папке `dist\`.

---

## Если что-то не так

- **`node` не найден** — не установлен Node.js (см. выше).
- **`npm install` падает с ECONNRESET / ETIMEDOUT** — сеть оборвала загрузку.
  Запусти файл ещё раз (докачка продолжится) или включи VPN.
- **Вкладки пустые / «command not found: claude»** — не работает сам
  `claude` в терминале. Приложение тут ни при чём — почини Claude Code.
- **Claude не стартует сам в новой вкладке** — в `main.js` есть задержка
  `setTimeout(..., 350)` перед вводом команды (строка ~370). PowerShell
  стартует иначе, чем маковский шелл; увеличь число (например до 800) и
  перезапусти.

> Важно: если осталась папка `node_modules` от прошлой неудачной попытки —
> удали её перед повторным запуском, иначе скрипт пропустит установку.
