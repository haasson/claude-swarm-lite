# Claude Swarm Lite — инструкция для пользователя

Пульт для нескольких сессий Claude Code сразу. Каждая вкладка — настоящий процесс
`claude`, запущенный в твоём login-шелле. Приложение **не трогает токены и авторизацию**:
работает на твоей обычной подписке, ровно как `claude` в терминале. Вместо прыганья по
вкладкам терминала ты видишь дашборд — кто работает, кто ждёт ответа, кто закончил.

macOS, Apple Silicon (arm64).

---

## Что нужно до старта

1. **Claude Code установлен и залогинен.** Проверь в терминале:
   ```bash
   claude --version
   ```
   Если команды нет — сначала поставь и авторизуй Claude Code. Swarm просто запускает
   этот же `claude`, так что без него работать не будет.

2. **macOS на Apple Silicon** (M1/M2/M3/…). Сборка — arm64.

---

## Установка (для обычных пользователей)

1. Возьми файл **`Claude Swarm Lite-0.1.0-arm64.dmg`** (папка `dist/` в проекте).
2. Открой `.dmg`, перетащи **Claude Swarm Lite** в **Applications**.
3. Первый запуск — приложение без подписи, macOS ругнётся:
   - Открывай через **правый клик по иконке → Open → Open**, а не двойным кликом.
   - Либо: **Системные настройки → Приватность и безопасность → Open Anyway**.
   Это делается один раз.

> При первом запуске в новой папке macOS может спросить доступ к файлам — разрешай,
> это нужно `claude`, чтобы читать проект.

---

## Запуск из исходников (для разработчиков)

```bash
npm install     # ставит зависимости и пересобирает node-pty под ABI Electron
npm start       # запускает приложение
```

Собрать свой `.dmg`:
```bash
npm run dist    # результат в dist/
```

## Как пользоваться

### Создать агента
- **⌘T** — новая вкладка в папке по умолчанию (`~/ClaudeSwarm`).
- **⌘O** — новая вкладка с выбором рабочей папки (folder picker). Запускай агента прямо
  в папке нужного проекта — так `claude` видит твой код.

Каждая новая вкладка сама запускает `claude` и подхватывает твою авторизацию.

### Переключение и закрытие
- **⌘1 … ⌘9** — прыгнуть на вкладку по номеру.
- **⌘W** — закрыть текущего агента (процесс `claude` завершается).

### Раскладка
- **⌘L** — переключить вид: рейл слева ⇄ плашки-дашборд сверху. Выбор запоминается.

### Панель команд
- **⌘K** (или кнопка-бургер) — меню команд: встроенные + автоматически найденные
  кастомные слэш-команды и скиллы **этого проекта** (`.claude/commands`, `.claude/skills`)
  и глобальные (`~/.claude/…`). Команды с «…» ждут, что ты допишешь аргумент.

### Организация карточек
- **Двойной клик** по названию карточки — переименовать (можно в несколько строк).
- **Drag & drop** — перетаскивай карточки и группируй их по папкам.

## Статусы агентов

Цвет карточки показывает, что происходит, без чтения терминала:

| Статус | Что значит |
|--------|-----------|
| 🟠 **работает** | Claude активно печатает / думает / гоняет инструмент |
| 🟡 **ждёт ответа** | остановился на вопросе или запросе разрешения — нужен ты |
| 🟢 **готов** | закончил, ждёт нового задания |
| ⚪ **завершён** | сессия закрыта / процесс вышел |

Статус берётся из трёх источников, в порядке старшинства:

1. **Хуки Клода** (включаются в «Настройки → Запуск») — единственный канал, который
   видит диалоги: «просит разрешение», «задал структурный вопрос».
2. **Стенограмма** — Клод пишет каждое сообщение в свой журнал по ходу дела, и
   приложение его читает. Отсюда «работает / думает / конец хода» без угадывания, и
   отсюда же берётся текст вопроса — дословно и целиком, даже если на экране он уже
   уехал вверх. Вкладка привязана к своему журналу точно, файлы не путаются.
3. **Экран** — подстраховка: диалог разрешения виден только там, и там же работает
   старая логика для вкладок, где Клод запущен не приложением.

Один случай не виден ни одному каналу сам по себе: Клод заканчивает ход одинаково и
когда работа сделана, и когда он задал вопрос текстом. Отличает их только то, как
агент заканчивает сообщение — по умолчанию «Сейчас от тебя: …». Свой список фраз
задаётся в «Настройки → Запуск» (по одной в строке); «Сейчас от тебя: ничего,
жди…» вопросом не считается.

### Фоновые уведомления
Когда агент в фоне переходит в **«ждёт ответа»** или **«готов»**, прилетает системное
уведомление macOS. Клик по нему выводит приложение на передний план к нужной вкладке —
можно запускать несколько агентов и не сидеть, уставившись в экран.

## Телеграм: отвечать агентам с телефона

Встал из-за компьютера — агенты продолжают писать. «Настройки → Телеграм» связывает их
с вашим телефоном.

**Настройка, один раз.**
1. В Телеграме напишите `@BotFather` → `/newbot` → получите токен вида `1234567890:AA…`.
   Бот ваш: приложение обращается только к Telegram, никакого промежуточного сервера.
2. Вставьте токен в «Настройки → Телеграм» → «Подключить». Ниже появится «@ваш_бот на связи».
3. «Привязать чат» → отсканируйте QR телефоном → «Начать». Всё: сворм запомнил этот чат.
   Знаете id группы — рядом есть поле «привязать по id», код тогда не нужен.
   Хотите вкладки отдельными темами — заведите форум-супергруппу, добавьте туда бота
   **администратором с правом управлять темами** и отсканируйте код там. Админство тут не
   косметика: без него Телеграм (режим приватности ботов) не покажет боту обычные
   сообщения в топиках — только реплаи на его собственные. Приложение проверит права само
   и скажет прямо, чего не хватает; кнопка «Проверить права» перепроверит после правки.

**Как этим пользоваться.** Агент упёрся в вопрос — вопрос приходит в чат вместе с именем
вкладки и текстом. Отвечаете **реплаем** на это сообщение (или просто пишете в топик
нужной вкладки) — текст уходит в живую сессию, как будто вы набрали его на клавиатуре.
Когда агент закончит ход, его ответ придёт в тот же чат — так замыкается круг «дал
задачу из телеги → увидел результат».

**Задача с нуля.** Отвечать реплаем не на что, поэтому скажите, кому пишете: `/use api` —
и дальше обычные сообщения в этом чате (или в этом топике) уходят во вкладку `api`.
`/use` без имени покажет текущую, `/tabs` — список всех со статусами.

**Агент знает, что вы в телеге.** К сообщениям из телеги приложение добавляет метку и
просьбу отвечать коротко, без стен кода и без интерактивного выбора вариантов — такой
выбор с телефона просто нечем нажать. При включённых хуках это не просьба, а запрет:
инструмент с вариантами блокируется, и агент переспрашивает текстом. Формулировку можно
переписать под себя в том же разделе настроек. Как только вы тронете клавиатуру в этой
вкладке, режим снимается — вы вернулись за стол, значит и большие ответы, и варианты
снова уместны.

**Мак не должен спать.** Агенты живут на нём, поэтому со спящим маком отвечать некому.
В настройках есть галочка «не давать маку засыпать, пока чат привязан» (включена).
Если мак всё-таки уснул — Телеграм придержит ваши сообщения и отдаст их, когда
приложение проснётся.

**Чего мост намеренно не делает.**
- Не угадывает вкладку. Нет реплая и нет топика — придёт «не понял, какой вкладке»,
  а не попытка догадаться: ответ, уехавший в чужую задачу, хуже отсутствия ответа.
- Не отвечает на **запросы разрешения**. О них сообщит, но подтвердить выполнение
  команды можно только за компьютером, где видно, что именно одобряется.
- Не слушает чужих. Привязан ровно один чат; сообщения из любого другого игнорируются.

**Что нужно знать про доступ.** Приложение само звонит на `api.telegram.org` (long
polling): наружу не открывается ни порт, ни адрес, VPS не нужен. Обратная сторона —
если Телеграм у вас работает только через VPN, то и мост тоже. Токен хранится
зашифрованным ключом системного keychain; в интерфейсе он больше не показывается,
только маска — если потеряли, выпустите новый у BotFather.

Голосовой ввод — следующим этапом.

## Типичный сценарий

1. **⌘O** → выбираешь папку проекта → агент стартует в ней.
2. Даёшь задачу, он уходит в **работу** (🟠).
3. Переключаешься **⌘T / ⌘O** на второго агента в другом проекте.
4. Первый упёрся в вопрос → уведомление + карточка стала 🟡 → возвращаешься, отвечаешь.
5. Позеленел (🟢) — даёшь следующую задачу или **⌘W** закрываешь.

## Если что-то не так

- **«claude: command not found» во вкладке** — Claude Code не в PATH login-шелла.
  Проверь, что `claude --version` работает в обычном терминале; поправь `~/.zshrc`.
- **Не запускается после установки** — открой через правый клик → Open (см. «Установка»).
- **Ложный «готов» на долгой паузе** — приложение специально давит такие ложняки, но при
  очень тихих операциях статус может дёрнуться; ориентируйся по самому терминалу вкладки.
- **Сыплются запросы доступа к файлам** — запускай агентов в конкретных рабочих папках
  (**⌘O**), а не в домашней директории.
