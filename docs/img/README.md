Кидайте сюда PNG ровно с этими именами. В `README.md` под каждый кадр уже стоит
помеченное место (`<!-- ФОТО N · docs/img/… -->`) — как только файл появится, комментарий
меняется на картинку.

Порядок съёмки — снизу вверх по списку не обязателен; кадры независимы, недостающие можно
добавлять по одному.

## Что стоит проверить перед съёмкой

- **Retina как есть.** Снимайте на маке штатным ⇧⌘4 (пробел — окно целиком, с тенью), масштаб не уменьшайте: гитхаб отдаст картинку в нужном размере сам.
- **Одна тема на весь набор.** Половина кадров в тёмной, половина в светлой смотрится как разные программы.
- **Имена проектов и пути.** В кадр попадают названия папок и вывод терминала — проверьте, что там нет ничего чужого или личного.
- **Токены.** В «Настройки → Телеграм» токен показан маской, но перед съёмкой лишний раз убедитесь.
