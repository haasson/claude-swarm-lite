# Тема терминала — дизайн

**Дата:** 2026-07-09
**Статус:** утверждён к реализации

## Задача

Дать пользователю сменить внешний вид полотна терминала: выбрать цветовую
палитру из готовых пресетов, а также настроить шрифт и курсор. Сейчас тема
зашита в `makeXterm()` (`renderer/renderer.js`) — одна тёмная палитра на все
сессии, менять нечем.

## Охват (решения брейншторма)

- **Что перекрашивается:** только полотно xterm (фон, текст, ANSI-палитра,
  курсор). UI приложения (сайдбар, панели, модалки) не трогаем.
- **Способ выбора:** готовые пресеты палитр + настройка шрифта (размер,
  семейство) и курсора (форма, мигание). Ручного color-picker нет.
- **Область действия:** одна глобальная тема на всё приложение — применяется ко
  всем открытым и новым вкладкам (как текущие настройки уведомлений).

## Архитектура

Три единицы с чёткими границами:

### 1. Данные тем — `renderer/themes.js`

Новый файл, подключается `<script src="./themes.js">` в `index.html` **перед**
`renderer.js`. Экспортирует глобал `window.SWARM_THEMES` — массив пресетов:

```js
{ id: 'swarm-dark', name: 'Swarm Dark', xterm: { /* полный ITheme */ } }
```

`xterm` — полный объект темы xterm.js: `background`, `foreground`, `cursor`,
`cursorAccent`, `selectionBackground` и 16 ANSI-цветов (`black`…`white` +
`brightBlack`…`brightWhite`).

Стартовый набор из 6 тем:

| id             | name           | тип    |
|----------------|----------------|--------|
| `swarm-dark`   | Swarm Dark     | тёмная (текущий дефолт, фон `#0d0f12`) |
| `light`        | Light          | светлая |
| `solarized-dark` | Solarized Dark | тёмная |
| `dracula`      | Dracula        | тёмная |
| `nord`         | Nord           | тёмная |
| `gruvbox-dark` | Gruvbox Dark   | тёмная |

`swarm-dark.xterm` побайтово повторяет текущий зашитый дефолт (регресс-защита —
поведение по умолчанию не меняется).

### 2. Состояние — localStorage `swarm.appearance`

Один JSON-ключ в стиле существующих `swarm.*`:

```json
{ "theme": "swarm-dark", "fontSize": 13, "fontFamily": "<стек>",
  "cursorStyle": "block", "cursorBlink": true }
```

- `loadAppearance()` — читает и валидирует (см. «Обработка краёв»), возвращает
  нормализованный объект. Дефолты: `theme: 'swarm-dark'`, `fontSize: 13`,
  `fontFamily` — текущий стек `'ui-monospace, "SF Mono", Menlo, monospace'`,
  `cursorStyle: 'block'`, `cursorBlink: true`. Дефолт `block` сохраняет текущее
  поведение (сейчас `makeXterm` не задаёт `cursorStyle` → xterm берёт `block`).
- `saveAppearance()` — пишет ключ.
- Загрузка при старте — рядом с `applyLayout` / `applyNotify` в конце renderer.js.

### 3. Применение — `applyAppearance()`

Единственный источник правды для внешнего вида терминала:

- `makeXterm()` читает текущее состояние и создаёт xterm с нужными
  `theme` / `fontSize` / `fontFamily` / `cursorStyle` / `cursorBlink` — для
  **новых** вкладок.
- `applyAppearance()` проходит по всем **живым** сессиям, ставит
  `term.options.theme`, `term.options.fontSize`, `term.options.fontFamily`,
  `term.options.cursorStyle`, `term.options.cursorBlink`, затем `fit.fit()`
  (смена размера шрифта меняет геометрию — обязателен рефит, как в `applyLayout`).

Открытые вкладки перекрашиваются мгновенно, без перезапуска сессий.

### 4. UI — вкладка «Вид» в модалке Настроек

Добавляется в `showSettingsModal()` третьей вкладкой рядом с «Запуск» и
«Уведомления». Панель `data-panel="appearance"`:

- **Тема** — сетка кнопок-свотчей, по одной на пресет. Каждая показывает мини-
  палитру (фон + несколько ANSI-цветов) и имя. Активная подсвечена.
- **Шрифт** — степпер размера (диапазон 10–20) + выпадающий список семейств из
  нескольких безопасных системных моно-стеков.
- **Курсор** — селект формы (`bar` полоса / `block` блок / `underline`
  подчёркивание) + чекбокс «мигание».
- **Живой предпросмотр** — строка-образец: фон/текст/пара ANSI-цветов и курсор.
  Обновляется при выборе пресета/шрифта/курсора **до** сохранения.
- «Сохранить» → `saveAppearance()` + `applyAppearance()`. «Отмена» → откат
  (ничего не пишем, предпросмотр отбрасывается вместе с закрытием модалки).

## Обработка краёв

- Неизвестный `theme` или битый JSON в `swarm.appearance` → тихий фолбэк на
  `swarm-dark` и дефолты остальных полей.
- `fontSize` клампится в диапазон 10–20.
- `cursorStyle` вне {`bar`,`block`,`underline`} → `bar`.
- Смена шрифта/размера всегда сопровождается рефитом (иначе терминал обрежет
  последнюю строку/колонки).

## Тестирование

Проект гоняет `node test/detector.test.js` (`npm test`). Добавляем лёгкий
unit-тест `test/themes.test.js` (тем же стилем, без фреймворка):

- каждый пресет в `SWARM_THEMES` имеет непустые `id` и `name`;
- `id` уникальны;
- у каждого `xterm` присутствуют все обязательные ключи (фон, текст, курсор,
  выделение + 16 ANSI-цветов), значения — валидные hex-цвета;
- `swarm-dark.xterm` совпадает с текущим зашитым дефолтом (регресс).

`themes.js` пишется как обычный `<script>`-глобал; для теста в Node он должен
также экспортироваться через `module.exports` при наличии `module` (двойной
режим: браузер-глобал + CommonJS), чтобы тест мог его подключить.

## Вне охвата (YAGNI)

- Тема UI приложения (сайдбар/панели) — только терминал.
- Тема на вкладку — только глобально.
- Ручной подбор произвольных цветов (color-picker) — только пресеты.
- Импорт/экспорт тем, пользовательские пресеты.
