# Телеграм, второй заход: разрешения, голос, /new, зеркало итогов — Implementation Plan

**Goal:** довести мост до состояния «из дороги можно работать»: одобрять разрешения
кнопками, говорить голосом, открывать вкладку из телеги и видеть итоги, когда тебя нет
за маком.

**Решено пользователем 2026-07-28:** разрешения — делаем; голос — **локально,
whisper.cpp** (звук не покидает машину); трансляция итогов — **по отсутствию за маком**;
и всё это должно быть продумано **и для Windows**, не только для macOS.

## Task 1: Разрешения кнопками

Сейчас запрос разрешения приходит уведомлением, а ответить можно только за компьютером.
Меняем на: в сообщении текст того, что одобряется, и **реальные варианты, которые
предложил Клод**, кнопками. Нажал — приложение печатает соответствующий номер.

- `screen.js`: вытащить из снимка блок запроса — строку инструмента/команды и
  пронумерованные варианты. `OPTION_RE` уже есть, нужен разбор в список
  `[{ n, text }]` + отпечаток блока (хеш нормализованного текста).
- `telegram.js`: `inlineKeyboard(options)` → `reply_markup`; разбор `callback_query`
  в `readUpdate` (и `allowed_updates` пополнить — сейчас там только `message`).
- `main.js`: в сообщении о разрешении — клавиатура; на нажатие **сверить отпечаток**
  с текущим экраном вкладки. Не совпал → `answerCallbackQuery` с «этот запрос уже
  закрыт», ничего не печатаем. Совпал → `write(номер + '\r')`, ответ отредактировать
  в «✅ выбрано: 2. No».
- Пользователь одобряет только то, что видит: свободный текст в разрешение не уходит
  никогда, даже если прислать его реплаем.
- **Windows:** отличий нет — это чистая логика над снимком экрана и Bot API.

## Task 2: Голос → текст, локально

- Скачать файл: `getFile` → `api.telegram.org/file/bot<token>/<path>`. Формат — OGG/Opus.
- **Конвертация без ffmpeg:** Chromium умеет декодировать Opus сам. Отдаём байты в
  рендерер, там `OfflineAudioContext(1, len, 16000)` + `decodeAudioData` → моно 16 кГц
  Float32 → обратно в main → пишем 16-битный WAV. Ни ffmpeg, ни нативных модулей,
  одинаково на обеих ОС. Это ключевое решение: иначе тянуть ffmpeg в зависимости.
- Запуск бинарника: путь из настроек, иначе поиск в PATH по именам
  `whisper-cli`, `whisper-cpp`, `whisper`, `main` (+ `.exe` на Windows).
- Модель: путь из настроек. Автоматически **не скачиваем** — 150 МБ без спроса
  недопустимо; если модели нет, говорим в телегу «голос не настроен» и показываем
  в настройках, что скачать.
- Эхо: распознанный текст сначала присылаем в тему («услышал: …»), потом печатаем в
  сессию. Дешёвая страховка от «розовый пн» вместо «RoseVPN».
- **Windows:** brew нет. В настройках — своя инструкция на ОС: macOS `brew install
  whisper-cpp`, Windows — готовый бинарник из релизов whisper.cpp + путь в поле.
  Поиск в PATH и `.exe`-имена уже учтены выше.

## Task 3: `/new` — вкладка из телеги

- Тема = вкладка = папка, поэтому `/new` **в теме** значит «ещё один агент в этой же
  папке», и папку называть не нужно. В общей теме `/new` отвечает подсказкой.
- Вкладки рождаются в рендерере (xterm + DOM), поэтому main просит его через новый
  IPC в обратную сторону (`app:createTab` с cwd). Тема новой вкладке создастся сама.
- **Windows:** отличий нет.

## Task 4: Зеркало итогов по отсутствию за маком

- `powerMonitor.getSystemIdleTime()` (кроссплатформенный) > 5 мин → в группу идут итоги
  **всех** ходов, а не только задач из телеги. Вернулся за стол — только вопросы, как
  сейчас. Плюс галочка «транслировать всегда».
- Порог и галочку хранить там же, где остальные настройки моста.
- **Windows:** API работает; проверить, что бездействие считается так же (RDP-сессии
  могут врать — если врёт, галочка остаётся ручным выходом).

## Как проверять

- `npm test` — чистые модули (`telegram.js`, `screen.js`, разбор запроса и клавиатуры).
- Разрешения: включить хуки, дать агенту команду, требующую разрешения, нажать кнопку
  из телеги; отдельно — нажать кнопку **после** того как диалог закрыт за компьютером
  (должен прийти отказ, а не набор номера в чужой диалог).
- Голос: короткая фраза с названием продукта («RoseVPN») — проверить эхо.
- Windows: отдельный прогон по таблице выше на win-машине.
