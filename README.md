# Claude Swarm Lite

Мини-пульт для нескольких сессий Claude Code сразу. Каждая вкладка — настоящий
процесс `claude`, запущенный в login-шелле и наследующий твою авторизацию (никаких
токенов приложение не трогает — работает на твоей обычной подписке). Вместо прыганья
по вкладкам терминала видишь дашборд: кто работает, кто ждёт ответа, кто закончил.

Electron + node-pty + xterm.js.

## Запуск (из исходников)

```bash
npm install       # ставит зависимости + подтягивает node-pty под ABI Electron
npm start
```

Нужен установленный и залогиненный Claude Code (`claude --version` работает в терминале).

## Возможности

- Несколько независимых сессий Claude во вкладках (⌘T новая, ⌘W закрыть, ⌘1–9 переключение).
- Две раскладки (⌘L): рейл слева или плашки-дашборд сверху. Выбор запоминается.
- Статус каждого агента по цвету: **работает** / **ждёт ответа** / **готов** / **завершён**.
  Выводится из pty-потока (пока агент активен — спиннер сыплет байты; в тишине смотрим
  экран, чтобы отличить «ждёт разрешения» от «готов»).
- Нижний git-бар: ветка активной папки, переключение, fetch/pull (в стиле VS Code).

## Структура

| Файл | Что делает |
|------|-----------|
| `main.js` | Electron main: pty-сессии, детект статуса, IPC |
| `preload.js` | Мост `window.swarm` между рендером и main |
| `git.js` | git-пломбинг для нижнего бара (чистый Node) |
| `renderer/` | UI: вкладки, xterm-терминалы, раскладки, покраска статусов |
| `scripts/release.mjs` | Скрипт релиза (см. ниже) |

## Сборка и релиз

Приложение нативное, поэтому каждая ОС собирается на своей платформе:

- **macOS** (`.dmg`) — только на Mac: `npm run dist`. Только Apple Silicon (arm64).
- **Windows** (`.exe`) — на Windows-машине `npm run dist:win`, **или** в GitLab CI
  на Linux-раннере через Wine (node-pty подтягивает готовый win32-бинарь, компилятор
  не нужен). CI собирает `.exe` автоматически при пуше тега.

### Выпуск версии — одной командой

```bash
export GITLAB_TOKEN=<PAT с scope api>
npm run release -- patch      # или minor / major
```

Скрипт: поднимает версию, дописывает `CHANGELOG.md`, обновляет ссылки в этом README,
коммитит и ставит тег `vX.Y.Z`, собирает `.dmg` и заливает его в GitLab-реестр пакетов,
пушит `main` + тег. Пуш тега запускает CI: тот собирает Windows `.exe` и создаёт
**GitLab Release** со ссылками на обе сборки.

> Ссылки на сборки ведут в приватный GitLab и требуют доступа к репозиторию.

Полная история версий — в [`CHANGELOG.md`](CHANGELOG.md).
