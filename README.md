Swarm держит несколько сессий Claude Code в одном окне. Каждая вкладка — отдельный процесс `claude` в отдельной папке проекта, и вкладка красится по состоянию агента: работает, ждёт ответа, закончил.

Это нужно, чтобы вести три-четыре задачи параллельно и не следить за каждой: приложение само покажет и подскажет уведомлением, кто упёрся в вопрос. Когда вас нет за компьютером, ответить можно из Telegram, в том числе голосовым.

Своей авторизации у Swarm нет. Он вызывает тот же `claude`, что стоит у вас в терминале, и работает на вашей подписке. Токены приложение не читает и не хранит.

> **Что нужно:** macOS на Apple Silicon или Windows и установленный Claude Code.
> Проверка — команда `claude --version` в терминале.

## Что это даёт

| | |
|---|---|
| **Вкладка — это процесс** | Настоящий `claude` в вашем login-шелле, в выбранной папке. Не обёртка над API: работают ваши алиасы, ваш `~/.zshrc`, ваши слэш-команды. |
| **Цвет — это состояние** | Оранжевый работает, жёлтый ждёт вас, зелёный закончил. Состояние читается из журнала сессии, а не угадывается по картинке в терминале. |
| **Уведомление вместо слежки** | Агент в фоне упёрся в вопрос — прилетает системное уведомление. Клик открывает нужную вкладку. |
| **Пульт** | Очередь тех, кто ждёт ответа. Ответили одному — очередь сама перешла к следующему. |
| **Telegram** | Группа с темами: тема на вкладку. Пишете текст или голосовое, получаете ответ, разрешения даёте кнопками. |
| **Ничего снаружи** | Ни сервера, ни аккаунта, ни телеметрии. Бот в Telegram — ваш собственный, распознавание голоса — на вашей машине. |

## Установка

### Скачать сборку

<!--/DL-->

Открыть `.dmg`, перетащить **Swarm** в **Applications**. На Windows — обычный установщик, никаких дополнительных шагов.

> ### ⚠️ macOS: один шаг после скачивания браузером
>
> Первый запуск упрётся в «не удалось проверить разработчика». Карантин вешает на файл
> то приложение, которое его скачало, — то есть браузер. Снимается один раз:
>
> ```bash
> xattr -dr com.apple.quarantine /Applications/Swarm.app
> ```
>
> **Без терминала:** попробовать открыть Swarm, получить отказ, затем в **Системные
> настройки → Приватность и безопасность** нажать **Open Anyway** — раньше неудачной
> попытки этой кнопки там нет. Правый клик → Open, который работал на старых macOS,
> в 15 и новее отключён.

### Через npm — без этого шага

```bash
npx claude-swarm
```

Ставит ту же последнюю сборку, но **без карантина**: приложение окажется в «Программах» и откроется сразу. Карантин вешает скачавшая программа, а `curl` внутри установщика этого не делает.

Нужна Node 18 и старше. Для Windows установщика в npm нет — там `.exe` выше.

<details>
<summary><b>Ещё два способа: curl и сборка из исходников</b></summary>

<br>

**Одной командой без npm.** Тот же установщик, что внутри пакета `claude-swarm`, и с тем же результатом — без карантина.

```bash
curl -fsSL https://raw.githubusercontent.com/raul-cortez/claude-swarm/main/scripts/install.sh | sh
```

Он короткий и читаемый — [посмотрите его глазами](scripts/install.sh), прежде чем запускать что-то из интернета в своей оболочке.

**Собрать у себя.** Видно, что именно собираете. Нужны git и Node; первая сборка дольше остальных способов — качается Electron.

```bash
git clone https://github.com/raul-cortez/claude-swarm.git
cd claude-swarm && npm ci && npm run install-app
```

`install-app` собирает приложение без `.dmg` и кладёт в «Программы» (папку переопределяет `SWARM_DEST`). Карантина у собранного локально не бывает.

</details>

### Обновления

Приложение само находит новые версии и ставит их по кнопке. Переустанавливать не нужно, каким бы способом вы ни начали.

<!-- ФОТО 2 · docs/img/02-updates.png · «Настройки → Обновления»: текущая версия и кнопка обновления. -->

<details>
<summary>Почему обновление не может сломать установку</summary>

<br>

Скачивается только код, несколько мегабайт; бандл в «Программах» не трогается никогда. Поэтому подпись не ломается, а выданные системой разрешения на папки не сбрасываются.

Если обновление окажется битым, приложение поднимется на прежней версии — запасной путь всегда бандл. Полный установщик нужен редко, только при смене версии Electron или нативных модулей, и приложение об этом скажет.

</details>

## Первые пять минут

1. **＋ новая сессия** (или **⌘O**) — выберите папку проекта. Агент стартует в ней и видит ваш код.
2. Дайте задачу. Вкладка станет 🟠 **работает**.
3. **⌘O** ещё раз — второй агент в другом проекте. Переключение: клик по карточке или **⌘1…9**.
4. Первый упёрся в вопрос → уведомление, карточка 🟡. Возвращаетесь, отвечаете.
5. Позеленел 🟢 — даёте следующую задачу или закрываете вкладку крестиком.

> 💡 Заводите агентов **в папках проектов**, а не в домашней: иначе macOS засыплет вас
> запросами доступа к файлам, и отвечать придётся за каждую папку, куда агент заглянет.

## Вкладки и статусы

     видно цвет, подпись состояния и таймер ожидания. -->

| Цвет | Состояние |
|:---:|---|
| 🟠 | **работает** — печатает, думает, гоняет инструмент |
| 🟡 | **ждёт ответа** — и видно, чего именно ждёт: разрешение или вопрос |
| 🟢 | **ход закончен** |
| ⚪ | **сессия закрыта** |

### Откуда берётся состояние

Из трёх источников по старшинству:

| | Источник | Что даёт |
|:---:|---|---|
| 1 | **Хуки Клода** | Единственный канал, который видит диалоги и точно различает «просит разрешение» и «задал вопрос». Включаются галочкой в «Настройки → Запуск» и только для вкладок, запущенных приложением; глобальный `~/.claude/settings.json` не меняется. |
| 2 | **Журнал сессии** | Клод пишет каждое своё сообщение в `~/.claude/projects/**.jsonl` по ходу дела. Отсюда «работает / думает / конец хода» без угадывания и дословный текст вопроса — целиком, даже если на экране он уже уехал вверх. |
| 3 | **Экран** | Подстраховка: запрос разрешения в журнал не попадает, он живёт только на экране. |

Один случай не виден ни одному каналу сам по себе: **Клод заканчивает ход одинаково и когда работа сделана, и когда задал вопрос текстом.** Отличает их только то, чем агент заканчивает сообщение — по умолчанию фразой «Сейчас от тебя: …».

Просить об этом агента руками не нужно. Галочка **«Просить агента звать вас»** добавляет просьбу прямо в запуск вкладки, не трогая ваши файлы. Свои фразы задаются там же, по одной в строке, и рядом есть поле, где введённый хвост сообщения сразу проверяется на совпадение.

Если тот же агент нужен вам и вне Swarm — кнопка **«Скопировать правило для CLAUDE.md»** отдаёт то же правило готовым блоком.

### Карточка и уведомления

Карточка показывает статус, время ожидания, заполнение контекста и число работающих сабагентов. Всё это по отдельности выключается в «Настройки → Вкладки» — там же плотность, размеры шрифтов и цвета статусов.

Когда агент в фоне переходит в «ждёт ответа» или «готов», приходит системное уведомление; клик по нему открывает нужную вкладку. Каждое из двух событий, звук и пинг активной вкладки в фокусе включаются отдельно.

## Окно

### Вкладки

**Создать** — кнопка **＋ новая сессия** спрашивает папку и запускает в ней агента. Вкладки группируются по папкам, поэтому несколько агентов на один проект не путаются с агентами на другой; группы сворачиваются.

**Организовать** — клик по карточке переключает на её терминал, крестик закрывает вкладку вместе с процессом, с подтверждением. Двойной клик по имени переименовывает, можно в несколько строк. За левый край карточку можно перетащить.

**Раскладка** — рейл слева или плашки-дашборд сверху, **⌘L**.

<!-- ФОТО 6 · docs/img/06-layouts.png · две раскладки рядом: рейл слева и дашборд сверху на одних и тех же вкладках. -->

### Пульт

Отдельная вкладка **⌘0**: очередь всех, кто ждёт ответа, с таймером у каждого и терминалом выбранного. Отвечаете — очередь сама переходит к следующему.

Это режим «разгрести накопившееся», когда вы отошли на полчаса и вернулись к четырём жёлтым карточкам. Счётчик ожидающих стоит на самой вкладке Пульта, так что заходить в него, чтобы узнать, нужны ли вы кому-то, не приходится. Выключается в «Настройки → Вид».

<!-- ФОТО 7 · docs/img/07-pult.png · Пульт со счётчиком и очередью ожидающих. -->

### Панель команд · ⌘K

Встроенные команды плюс автоматически найденные слэш-команды и скиллы **этого проекта** (`.claude/commands`, `.claude/skills`) и глобальные из `~/.claude/`. Команды с многоточием ждут, что вы допишете аргумент.

Искать нужную в списке быстрее, чем вспоминать её имя.

<!-- ФОТО 8 · docs/img/08-commands.png · открытая панель ⌘K с поиском и списком команд. -->

### Git-бар

Ветка папки активной вкладки, состояние относительно сервера и счётчик изменений с диффом по клику.

| Значок | Что значит |
|:---:|---|
| `*` | есть незакоммиченные правки |
| `↓N` | на сервере N новых коммитов |
| `↑N` | у вас N неотправленных |

Клик по имени ветки даёт меню: **Обновить** (свериться с сервером), **Подтянуть** (появляется, когда есть `↓`) и список веток по свежести — клик переключает.

Смотреть и переключать ветки можно всегда, это локально. `fetch` и `pull` ходят на сервер и требуют, чтобы вы были залогинены в git — если нет, приложение объяснит, как это сделать. Если папка вкладки не репозиторий, бар пустой.

<!-- ФОТО 9 · docs/img/09-gitbar.png · нижняя панель крупно: ветка со значками и счётчиком изменений. -->
<!-- ФОТО 10 · docs/img/10-diff.png · открытый дифф. -->

### Контекст и расход

Приложение подставляет вкладке свою строку статуса Клода, и она отдаёт два числа: насколько заполнен контекст этой сессии и как израсходованы окна подписки на 5 часов и на неделю, со временем сброса.

Заполнение видно прямо на карточке вкладки, полная картина приходит по `/usage` в Telegram — списком, самые полные сверху. Это ответ на вопрос «кого пора сжимать».

> **Плата за это одна:** ваша собственная строка статуса Клода во вкладках Swarm заменена.
> Так и задумано, флаг `--settings` сильнее пользовательских настроек. Вне Swarm ваша
> строка остаётся на месте.

## Что запускается во вкладке

«Настройки → Запуск» задаёт, что стартует в **новых** вкладках; уже открытые сессии настройки не трогают.

<!-- ФОТО 11 · docs/img/11-settings-launch.png · «Настройки → Запуск» целиком. -->

**Команда запуска.** Обычно `claude`, но это просто строка с флагами: `cld --model sonnet`, `claude-glm`, ваш алиас. Команд можно завести несколько — тогда при открытии вкладки приложение спросит, какую (в списке будет и «Чистый терминал»), либо возьмёт ту же, что в первой вкладке этой папки. Отдельный режим — **всегда открывать чистый терминал**, без всякой команды.

**Запоминание.** Набрали лончер в терминале вкладки руками — приложение привяжет его к этой вкладке и сделает умолчанием для новых. Ловится именно набранное или вставленное: команда, поднятая из истории стрелкой вверх, не считается.

**Режим разрешений.** Вкладки стартуют в выбранном режиме — manual, edits, plan, auto. Дальше он переключается как обычно, Shift+Tab. Смысл настройки в том, что с телефона Shift+Tab не нажать, а задать режим заранее — можно.

**Восстановление диалогов.** Папка и имя вкладки запоминаются всегда, а вернуться после перезапуска в тот же разговор — опция, выключенная по умолчанию.

> **Аккаунт и модель живут в вашем шелле, а не в приложении.** Swarm наследует окружение
> от того, кто его запустил, и просто печатает команду. Нужен конкретный аккаунт или свой
> `ANTHROPIC_BASE_URL` — пропишите `export` в `~/.zshrc`: каждая вкладка поднимает
> login-шелл и подхватит их даже при запуске из Finder. Правки действуют на новые вкладки,
> не на открытые.

## Telegram

Мост связывает вкладки с группой в Telegram: **тема на вкладку**. Список тем в телефоне — это список агентов, и по каждому сразу видно, работает он, ждёт вас или закончил.

<!-- ФОТО 12 · docs/img/12-tg-topics.png · телефон: список тем группы, по теме на вкладку. -->

### Настройка, один раз

Три шага в «Настройки → Телеграм», у каждого своя галочка готовности:

1. **Бот.** `@BotFather` → `/newbot` → токен вида `1234567890:AA…` в первый шаг. Бот — это аккаунт в Telegram, а не программа на сервере: размещать и платить нечего.
2. **Группа.** Создайте группу (можно одному), включите в ней **«Темы»**, нажмите «Привязать группу», отсканируйте QR и отправьте показанный код в группу. Код живёт 15 минут.
3. **Админство.** Сделайте бота администратором группы.

Под вторым шагом висит живой список требований — группа, темы, бот в группе, админство, право «Управление темами», право «Удаление сообщений». Каждый пункт с галочкой или крестиком: поправили в Telegram — нажали «Проверить ещё раз».

> **Нужна именно группа с темами.** Вкладок много, и различать их на телефоне можно только
> темами. Личный чат приложение привязывать откажется, а без админства режим приватности
> ботов вообще не покажет боту обычные сообщения.

<!-- ФОТО 13 · docs/img/13-settings-telegram.png · «Настройки → Телеграм»: мастер из трёх шагов и список требований. -->

### Как этим пользоваться

В теме нужной вкладки просто пишете текст — он уходит в живую сессию, как будто вы набрали его на клавиатуре. Ни реплаев, ни команд для этого не нужно: **тема и есть адрес**.

Ответ агента приходит туда же, целиком и с разметкой: жирное, курсив, код, блоки кода и ссылки переводятся в разметку Telegram, а не приезжают звёздочками.

<!-- ФОТО 14 · docs/img/14-tg-chat.png · телефон: диалог в теме вкладки — задача текстом и ответ агента. -->

**Разрешения — кнопками.** В сообщении видно команду, которую одобряете, и полный список вариантов текстом; кнопки под ним пронумерованы.

<!-- ФОТО 15 · docs/img/15-tg-permission.png · телефон: запрос разрешения с командой, списком вариантов и кнопками. -->

<details>
<summary>Почему список и кнопки дублируют друг друга — и почему «да» текстом не принимается</summary>

<br>

Кнопку Telegram рисует одной строкой и лишнее обрезает: вариант вида «Yes, and don't ask again for rm commands in this project» на ней не прочитать. Поэтому варианты идут дважды — полным списком в тексте и метками на кнопках. Читаете список, нажимаете номер.

Написать «да» текстом нельзя: одобрить можно только то, что было в списке. Если запрос успели закрыть за компьютером, кнопка так и ответит и ничего в сессию не напечатает.

</details>

**Голосом.** Запишите голосовое в тему вкладки — Swarm распознает его **на вашем маке** (whisper.cpp, звук никуда не уходит) и пришлёт эхо услышанного. Эхо не для красоты: распознавание ошибается на названиях продуктов, и увидеть это надо до того, как агент начнёт по нему работать.

Включается одной кнопкой «Включить голосовые» — по ней приложение само скачает распознаватель и модель. В сборке их нет, поэтому кому голос не нужен, тот не платит за него ни весом обновления, ни местом на диске.

<!-- ФОТО 16 · docs/img/16-tg-voice.png · телефон: голосовое и ответное эхо «🎙 услышал: …». -->

**Картинкой.** Скриншот в тему — самый быстрый способ показать агенту, что случилось: пересказывать красную простыню из терминала пальцами никто не станет. Файл ложится во временную папку на этом же компьютере, агент смотрит его сам, подпись становится задачей.

Всё остальное — видео, кружки, стикеры — мост брать не умеет и так и скажет.

**Имена и темы держатся вместе в обе стороны.** Переименовали вкладку на маке — переименуется тема; переименовали тему пальцем в дороге — переименуется вкладка. Тема заводится вместе со вкладкой и исчезает вместе с ней. Закрыли тему руками, пока вкладка работает, — бот спросит, вернуть тему или закрыть вкладку: молча завершать агента по жесту в чате он не станет.

### Где вы сейчас

От этого зависит, разговорчив ли мост:

| Положение | Что мост пишет сам | Писать агенту из чата | Сон мака |
|---|---|---|---|
| **за компом** | ничего | нельзя — развернёт кнопкой | как обычно |
| **за телефоном** | вопросы, разрешения, итоги всех ходов | можно | мак не засыпает |

Смотреть можно всегда: `/tabs`, `/last`, `/usage` работают в любом положении. А писать агенту — только «за телефоном». Отправленное за компом мост вернёт в ту же тему с кнопкой **📱 включить режим телефона**: нажали — текст ушёл, набирать второй раз не надо. Ждёт он полчаса.

Пока выбрано «за телефоном», **вся нижняя панель приложения подкрашена янтарным**. Садясь за стол, вы не разглядываете значки в углу, а знать надо сразу.

<!-- ФОТО 17 · docs/img/17-amber-bar.png · нижняя панель в янтарном режиме «за телефоном» и переключатель положения. -->

Ушли и забыли переключить — скажите боту `/phone`: он сделает то же самое и досошлёт итоги ходов, которые закончились, пока зеркало было выключено.

<details>
<summary>Почему граница именно здесь, а не «пиши всегда»</summary>

<br>

«Наполовину с телефона» — состояние, которого с телефона не видно. Сообщения доезжают, ход идёт, ответ возвращается, а мак посреди хода засыпает: не спать ему велит только положение «за телефоном». Остальные вкладки при этом молчат, и вопрос с вариантами в них нечем ни выбрать, ни закрыть.

Приложение не угадывает, когда вы вернулись, и это осознанно: момент, когда человек встал из-за стола, знает только человек. По простою мыши выходило и «зеркало включилось само, пока я читал», и — хуже — «первые итоги пропали», потому что они приходят в первые минуты после того, как вы встали.

</details>

**Агент знает, что вы в телеге.** К сообщениям из чата приложение добавляет просьбу отвечать по-телефонному — без стен кода и без интерактивного выбора вариантов, такой выбор с телефона просто нечем нажать. При включённых хуках это не просьба, а запрет.

Насколько подробно отвечать — отдельная настройка: «Кратко» (по умолчанию) или «Полностью». Это именно просьба к агенту, а не обрезка готового ответа: оборванная на полуслове мысль хуже коротко изложенной. Тронули клавиатуру в этой вкладке — режим снялся.

### Команды бота

| Команда | Что делает |
|---|---|
| `/tabs` | вкладки и их состояние; имя вкладки — ссылка в её тему |
| `/last` | что агент сказал последним, даже если он ещё работает |
| `/phone`, `/comp` | где вы сейчас: писать обо всём и не давать маку спать — или молчать |
| `/mode` | режим разрешений вкладки: manual, edits, plan, auto |
| `/usage` | заполнение контекста по вкладкам, окна подписки на 5 часов и неделю со временем сброса |
| `/new` | ещё один агент в папке этой темы |
| `/sync` | привести темы в соответствие с вкладками |
| `/help` | напоминалка по командам |

<!-- ФОТО 18 · docs/img/18-tg-tabs.png · телефон: ответ на /tabs со списком вкладок и их состоянием. -->

Любая другая команда со слэшем — не мостовая, а Клода: в теме вкладки она печатается прямо в её сессию, как если бы вы набрали её за клавиатурой. Так с телефона работают `/clear`, `/compact`, `/model`, `/agents` и ваши собственные команды из `~/.claude/commands`. Аргументы едут вместе с командой: `/compact сохрани решение по кэшу`.

Исключение одно — `/clear` спрашивает подтверждение кнопкой: стереть разговор нельзя отменить, а в меню у поля ввода он стоит пальцем рядом с `/comp`.

Отдельная вкладка настроек **«Клавиши»** задаёт модификатор для перемещения и удаления по словам и до края строки — и хоткей переноса строки, если привычный вам не совпадает с умолчанием.

## Другие агенты, кроме Клода

Swarm сделан под Claude Code. Команда вкладки задаётся руками, так что технически там запустится любой консольный агент или просто шелл — вкладки, терминалы, группировка по папкам, git-бар и отправка текста из Telegram работают с чем угодно.

Но всё, что делает Swarm пультом, а не набором терминалов, опирается на Клода:

| Что | Что будет с чужим агентом |
|---|---|
| **Статус вкладки** | Остаётся разбор экрана, написанный под интерфейс Клода: «работает» ещё угадывается, «ждёт ответа» и «готов» — уже нет. |
| **Разрешение против вопроса** | Диалог разрешения опознаётся по тексту Клода, у другого агента этот тип запроса не различается. |
| **Вопрос целиком** | Дословный текст берётся из журнала. Без него остаётся то, что видно на экране, с обрывками по краю. |
| **Уведомления и Пульт** | Следуют за статусом и наследуют всю его неточность: очередь может недосчитать или позвать зря. |
| **Разрешения кнопками** | Кнопки собираются из вариантов, которые предложил Клод. У другого агента их не будет. |
| **`/usage` и контекст** | Цифры приходят от строки статуса, которую приложение ставит только Клоду. |
| **«Позови меня» и режим разрешений** | Передаются флагами `--append-system-prompt` и `--permission-mode` и для чужой команды не добавляются: неизвестный флаг обычно не игнорируется, а роняет запуск. |
| **Восстановление сессий** | Через `--resume` Клода; для остальных вкладка начнётся с чистого разговора. |

Чинить в настройках ничего не нужно: приложение само смотрит на команду запуска и не применяет к чужому агенту то, что ему не подходит.

> **Обёртка вокруг Клода чужим агентом не считается.** Свой алиас с другим
> `CLAUDE_CONFIG_DIR`, другой моделью или своим бэкендом через `ANTHROPIC_BASE_URL` —
> это тот же Claude Code, и работает всё.

## Что уходит наружу

Ничего, кроме того, что и так ушло бы.

- **Аккаунта у Swarm нет**, регистрации нет, телеметрии нет. Приложение запускает `claude` и работает на вашей подписке; токены Клода оно не читает и не хранит.
- **Мост в Telegram** ходит на `api.telegram.org` сам (long polling). Наружу не открывается ни порт, ни адрес, VPS не нужен. Обратная сторона: если Telegram у вас работает только через VPN, то и мост тоже.
- **Бот — ваш собственный** и чужих не слушает: привязан ровно один чат, сообщения из любого другого игнорируются. Токен лежит в файле настроек приложения, доступном только вашей учётной записи, и в интерфейсе показывается маской.
- **Голос распознаётся локально**, whisper.cpp на вашей машине. Звук никуда не отправляется.
- **Обновления** — обычные файлы из релизов GitHub, проверяются по манифесту.

## Если что-то не так

<details>
<summary><code>claude: command not found</code> во вкладке</summary>

<br>

Claude Code не виден login-шеллу. Swarm запускает ровно эту команду, так что сначала проверьте `claude --version` в обычном терминале и поправьте `~/.zshrc`.

</details>

<details>
<summary>Приложение не открывается после установки</summary>

<br>

Снимите карантин — см. предупреждение в [«Установке»](#установка):

```bash
xattr -dr com.apple.quarantine /Applications/Swarm.app
```

</details>

<details>
<summary>macOS сыплет запросами доступа к файлам</summary>

<br>

Заводите агентов в папках проектов, а не в домашней.

</details>

<details>
<summary>Ложный «готов» на долгой паузе</summary>

<br>

Приложение специально давит такие ложняки, но при очень тихих операциях статус может дёрнуться — ориентируйтесь по самому терминалу вкладки.

</details>

<details>
<summary>Вкладка не отличает «ждёт ответа» от «готов»</summary>

<br>

Значит агент не заканчивает вопрос фразой из списка. Включите «Просить агента звать вас» или добавьте свою фразу в «Настройки → Запуск» — там же её можно сразу проверить.

</details>

<details>
<summary>Своя строка статуса Клода во вкладках заменена</summary>

<br>

Так и задумано, чинить нечего: флаг `--settings` сильнее пользовательских настроек, и именно из этой строки берутся заполнение контекста и окна подписки.

Ваша строка остаётся при запуске Клода вне Swarm — и вернётся во вкладке, если запустить его там руками, но вместе с ней уедут и полоска, и расход.

</details>

<details>
<summary>Бота выгнали из группы или разжаловали</summary>

<br>

Swarm узнает об этом сразу и скажет в панели настроек, а не будет молча показывать «мост в эфире».

</details>
