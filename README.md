# Swarm

Swarm держит несколько сессий Claude Code в одном окне. Каждая вкладка — отдельный процесс `claude` в отдельной папке проекта, и вкладка красится по состоянию агента: работает, ждёт ответа, закончил. Это нужно, чтобы вести три-четыре задачи параллельно и не следить за каждой: приложение само покажет и подскажет уведомлением, кто упёрся в вопрос. Когда вас нет за компьютером, ответить можно из Telegram, в том числе голосовым.

Своей авторизации у Swarm нет. Он вызывает тот же `claude`, что стоит у вас в терминале, и работает на вашей подписке. Токены приложение не читает и не хранит.

Требования: macOS на Apple Silicon или Windows, установленный Claude Code. Проверка — команда `claude --version` в терминале.

Сборка для macOS подписана ad-hoc, поэтому первый запуск система блокирует. Снять карантин с перетащенного в «Программы» приложения:

```bash
xattr -dr com.apple.quarantine /Applications/Swarm.app
```

После этого приложение открывается как любое другое. Без терминала тоже можно: попробовать открыть Swarm, получить отказ, затем в **Системные настройки → Приватность и безопасность** нажать **Open Anyway** — кнопка появляется там только после неудачной попытки. Обход через правый клик → Open в macOS 15 и новее не работает.

Новые версии Swarm находит сам и ставит по кнопке.

## Вкладки и статусы

```
┌─────────────┬─────────────┬─────────────┐
│ api      🟠 │ web      🟡 │ landing  🟢 │
│ работает    │ разрешение  │ готов       │
│ 1:42        │ 0:08        │             │
└─────────────┴─────────────┴─────────────┘
        ▼ терминал выбранной вкладки
  Bash(npm test) — разрешить?  1) Да  2) Нет
```

| Цвет | Состояние |
|---|---|
| 🟠 | работает: печатает, думает, гоняет инструмент |
| 🟡 | ждёт ответа, и видно, чего именно ждёт: разрешение или вопрос |
| 🟢 | ход закончен |
| ⚪ | сессия закрыта |

Состояние берётся из журнала сессии, который Клод пишет сам (`~/.claude/projects/**.jsonl`), а не угадывается по картинке в терминале. Поэтому вопрос виден дословно и целиком, даже если на экране он уже уехал вверх. Запрос разрешения в журнал не попадает — он живёт только на экране, оттуда и читается.

Когда агент в фоне переходит в «ждёт ответа» или «готов», приходит системное уведомление. Клик по нему открывает нужную вкладку.

## Как работать

Кнопка **＋ новая сессия** в списке спрашивает папку и запускает в ней агента. Так он видит код проекта. Вкладки группируются по папкам, поэтому несколько агентов на один проект не путаются с агентами на другой.

Клик по карточке переключает на её терминал, крестик на карточке закрывает вкладку вместе с процессом (с подтверждением, чтобы не убить работу случайно). Двойной клик по имени переименовывает вкладку, а за левый край карточку можно перетащить и сложить порядок под себя.

Когда ответа ждут сразу несколько агентов, в списке появляется вкладка **Пульт** со счётчиком. Внутри — чипы всех ожидающих с таймером и терминал выбранного. Отвечаете в него, и очередь сама переходит к следующему.

Внизу окна git-бар: ветка папки активной вкладки, переключение ветки, fetch/pull, счётчик изменений с диффом. Рядом кнопки **☰ команды** и **⚙ настройки**.

Сам список вкладок бывает двух видов: рейл слева или плашки-дашборд сверху. Переключается в «Настройки → Вид», там же и предпросмотр.

Настройки — переключателями в самом приложении. Ни файлы править, ни команды набирать не нужно нигде, кроме снятия карантина при установке.

## Telegram

Мост связывает вкладки с группой в Telegram: тема на вкладку. Список тем в телефоне — это список агентов.

```
Мои агенты
├── api        2   ❓ миграцию катать сразу или ждать?
├── web            ✅ собрал, тесты зелёные
└── landing        ✅ готов
```

В теме нужной вкладки просто пишете текст, он уходит в живую сессию. Ответ агента приходит туда же, целиком. Запрос разрешения приходит кнопками, в сообщении видно команду, которую одобряете. Голосовые распознаются на самой машине и наружу не уходят.

Настройка — три шага в «Настройки → Telegram», каждый с проверкой:

1. `@BotFather` → `/newbot`, полученный токен вставить в первый шаг.
2. Создать группу, включить в ней «Темы», нажать «Привязать группу» и отсканировать QR.
3. Сделать бота администратором.

Бот ваш собственный, сервер не нужен: приложение опрашивает Telegram само, наружу не открывается ни порт, ни адрес. Токен хранится зашифрованным ключом keychain.

| Команда | Что делает |
|---|---|
| `/tabs` | вкладки и их состояние |
| `/usage` | заполнение контекста по вкладкам, окна подписки на 5 часов и неделю со временем сброса |
| `/new` | ещё один агент в папке этой темы |
| `/sync` | привести темы в соответствие с вкладками |
| `/help` | напоминалка по командам |

## Другие агенты, кроме Клода

Swarm сделан под Claude Code. В «Настройки → Запуск» команда вкладки задаётся руками, так что технически там запустится любой консольный агент (или просто шелл, если выбрать режим чистого терминала) — вкладки, терминалы, группировка по папкам, git-бар и отправка текста из Telegram работают с чем угодно. Но всё, что делает Swarm пультом, а не набором терминалов, опирается на Клода, и с другим агентом отключится или начнёт врать:

- **Статус вкладки.** Про Клода приложение читает журнал его сессии и знает состояние точно. Для остальных остаётся разбор экрана, а он написан под интерфейс Клода: «работает» по выводу ещё угадывается, а «ждёт ответа» и «готов» — уже нет.
- **Разрешение против вопроса.** Диалог разрешения опознаётся по тексту Клода, так что у другого агента этот тип запроса не различается.
- **Вопрос целиком.** Дословный текст вопроса берётся из журнала. Без него остаётся то, что видно на экране, с обрывками по краю.
- **Уведомления и Пульт.** И то и другое следует за статусом, поэтому наследует всю его неточность: очередь ожидающих может недосчитать или позвать зря.
- **Разрешения кнопками в Telegram.** Кнопки собираются из вариантов, которые предложил Клод. У другого агента их не будет.
- **`/usage`.** Цифры расхода приходят от строки статуса, которую приложение ставит только Клоду.
- **Просьба «позови меня» и режим разрешений.** Передаются флагами `--append-system-prompt` и `--permission-mode`. Для чужой команды они не добавляются: неизвестный флаг обычно не игнорируется, а роняет запуск, и вкладка встретила бы вас мёртвой оболочкой.
- **Восстановление сессий после перезапуска** — через `--resume` Клода, для остальных вкладка начнётся с чистого разговора.

Ничего чинить в настройках для этого не нужно: приложение само смотрит на команду запуска и просто не применяет к чужому агенту то, что ему не подходит.

## Если что-то не так

- **`claude: command not found` во вкладке.** Claude Code не виден login-шеллу. Swarm запускает ровно эту команду, так что сначала проверьте `claude --version` в обычном терминале.
- **Приложение не открывается после установки.** Снимите карантин: `xattr -dr com.apple.quarantine /Applications/Swarm.app`, см. «Скачать».
- **macOS сыплет запросами доступа к файлам.** Заводите агентов в папках проектов, а не в домашней.
